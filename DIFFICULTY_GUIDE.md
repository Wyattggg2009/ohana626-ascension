# OHANA-626 — Wyatt's Six-Level Difficulty Switch

The story stays the same. The 20 chapters and 493 private voice recordings do **not** change. The switch changes the three relationship-themed BOLT questions in each chapter. All 60 questions use the same underlying relationship memories.

## How to change it (Chromebook, laptop, or tablet)

1. Open the OHANA-626 website and sign in as **Wyatt / Director**.
2. Open **The Magic Workshop** (`#/admin`).
3. Find **Wyatt's Private Challenge Control — Adjust Bella's puzzle difficulty**.
4. Choose a level and press **APPLY DIFFICULTY ♡**.
5. Bella will see the new difficulty on her **next unfinished BOLT**. If she's already on a puzzle, she'll be asked to load the updated version when she submits.

## The six levels

| Level | How it plays |
|---|---|
| Very Easy | Two possible answers |
| Easy (default) | Three possible answers |
| Medium | Four answers, including another distractor |
| Hard | Answer the same relationship question without answer choices |
| Extreme | Remember the answer and type its letters backwards, without spaces/punctuation |
| Impossible | Remember the answer, shift letters forward three alphabet positions, reverse the result, append the last digit of (chapter + seal + 6) |

The last mode is deliberately very hard but **still solvable**. The on-screen instructions give a harmless example.

## Progress and privacy

- No reset is performed. Finished seals and solved chapters stay solved.
- Chapter release dates and the final December 14 reveal are unchanged.
- Bella cannot change the Director-only setting. Supabase checks the correct answer for the active mode server-side.
- The change is global for **unfinished** BOLTs. Set it back to Easy at any time.
- Voice MP3s remain private and unchanged. Some older recordings may still refer to earlier puzzle mechanics.
- The game begins at **Easy** so the initial experience is friendly.

If Bella seems to be moving too quickly, try **Medium**, then **Hard** rather than jumping straight to Impossible. 💚
