OHANA-626 — Terminal and Door Interaction Fix

FIXES
- Nearby terminals can be interacted with without precise crosshair alignment.
- Click/tap directly on visible terminal or door labels.
- Allows using E or the INTERACT button when standing close by.
- Preserves the 15-day date locks and Supabase validation.
- Keeps existing mobile joysticks and responsive layout.

CHROMEBOOK GITHUB INSTALLATION
1. Open https://github.com/Wyattggg2009/ohana626-ascension
2. Upload escape-world.js from this ZIP to your repository root, replacing the old one.
3. Commit changes. Do not alter config.js or Supabase SQL.
4. Wait for Pages deployment, then Ctrl+Shift+R. On a phone, open a fresh private tab if needed.
5. Approach INCIDENT PRELUDE and tap/click its displayed label, or press E.

Note: this fixes client-side interaction, not date-locked access.
